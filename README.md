# 인근 실거래 분석

사업지 주소와 반경을 기준으로 아파트·오피스텔 실거래 및 분양 정보를 조회하는 단일 페이지 도구입니다.

## 바로 사용하기

개발이나 설치 없이 아래 주소를 열면 됩니다.

https://real-estate-analysis-tool-amber.vercel.app/

주소를 검색하고 조회 기간과 반경을 정한 뒤 **분석 시작**을 누르면 됩니다. 공공데이터 인증키는 Vercel에 안전하게 보관되어 있으므로 사용자가 따로 입력할 필요가 없습니다.

## 처음 공동 작업하는 분께

이 저장소는 웹페이지의 원본을 함께 보관하는 공간입니다. 초대를 수락했다고 바로 공개 페이지가 바뀌지는 않으니 안심하고 아래 순서대로 작업하면 됩니다.

1. Judy가 보낸 GitHub 공동 작업 초대를 수락합니다.
2. GitHub Desktop에서 이 저장소를 내려받습니다. 저장소 주소는 `https://github.com/bcm0928-judy/real-estate-analysis-tool`입니다.
3. `main`은 공개 중인 최종본이므로 직접 수정하지 않고, GitHub Desktop의 **Current branch > New branch**에서 자기 작업용 브랜치를 만듭니다. 이름은 `이름-수정내용`처럼 정하면 됩니다.
4. Claude나 다른 편집 도구에 내려받은 폴더를 열고 수정합니다. 화면과 동작 대부분은 `index.html`에 있습니다.
5. GitHub Desktop에서 변경 내용을 확인하고 **Commit**, **Push origin**을 차례로 누릅니다. Commit은 작업 내용을 저장하는 기록이고, Push는 그 기록을 GitHub에 올리는 동작입니다.
6. GitHub 저장소에 나타나는 **Compare & pull request**를 눌러 PR을 만듭니다. PR은 “내 수정본을 최종본에 합쳐주세요”라는 검토 요청입니다.
7. Judy가 내용을 확인해 Merge하면 `main`에 합쳐지고, Vercel이 공개 페이지를 자동으로 다시 배포합니다.

API 키나 비밀번호는 HTML, 채팅, GitHub에 직접 넣지 않습니다. 키 변경이 필요하면 저장소가 아니라 Vercel의 `DATA_SERVICE_KEY` 환경변수를 수정합니다.

## 사용 전 설정

1. Kakao Developers의 **앱 > 플랫폼 키 > JavaScript 키 > JavaScript SDK 도메인**에 배포 도메인을 등록합니다.
2. Vercel 프로젝트의 `DATA_SERVICE_KEY` 비밀 환경변수에 공공데이터포털에서 발급받은 일반 인증키(Decoding)를 등록합니다.
3. 페이지에서 주소를 검색한 뒤 **분석 시작**을 누릅니다.

API 인증키는 저장소나 브라우저에 포함되지 않으며 Vercel 서버리스 함수에서만 사용됩니다.

## 공급면적 (평당가 기준)

아파트 평당가는 공급면적 기준입니다. 공급면적은 아래 순서로 정합니다.

1. **건축물대장 실측** — 전유 + 주거공용(계단·복도 등). 분석이 끝나면 반경 안 아파트를 가까운 순서로 바로 조회합니다(30일 저장).
2. **청약홈 분양 공고** — 준공 전 단지.
3. **인근 실측 추정** — 대장에 주거공용이 없거나(전용률 90% 초과) 대장이 없는 단지. 같은 분석 반경에서 실측된 단지 중 준공 ±5년·전용 ±15㎡(모자라면 ±10년·±25㎡)의 전용률 중앙값을 씁니다. 표본이 3개 미만이면 4번.
4. **건축년도 기준 추정** — 고정 전용률표.

상세 패널의 「평형별」 표에서 3·4번으로 계산한 평형에는 「추정」 표시가 붙습니다.

## 준공 전 단지 (분양권)

분석할 때 「아파트 분양권전매 실거래가」도 함께 받습니다. 같은 법정동에 이름(또는 지번)이 같은 일반 매매 단지가 있으면 이미 준공된 것으로 보고 빼고, 나머지를 준공 전 단지로 지도에 올립니다. 라벨에 「분양권」 표시와 브라운 점선 테두리가 붙고, 평당가의 공급면적은 청약홈 공고의 실제 공급면적(공고를 못 찾으면 신축 전용률 추정)을 씁니다.

우측 상세 패널에는 **최초 분양가**(청약홈 주택형별 최고 분양가)를 주택형별로 보여 주고, 대표 평형 분양가를 세대수 가중 평균으로 냅니다. 대표 평형은 전용 84㎡이고, 공고에 84㎡가 없으면 세대가 가장 많은 평형입니다.

**PH(펜트하우스·최상층 특화) 제외 기준** — 두 조건을 모두 만족하는 주택형은 대표 분양가·프리미엄 계산에서 뺍니다.

1. 평당 분양가(최고가 ÷ 공급평)가 대표 평형보다 **30% 이상** 비싸다 (총액이 아니라 평당으로 비교)
2. 그 주택형 세대가 공고 전체의 **2% 미만**이다 (초고층·최상층에만 둔 소수 세대)

근거: 전국 공고 113건·주택형 754개를 실측한 결과, 평당 +20~30% 구간은 0개로 비어 있었고 +30% 이상 42개는 모두 세대 비중 1% 이하(1~7세대)였습니다. 그래서 경계를 빈 구간 위쪽인 30%로 둡니다. 주택형 이름의 P·T 표기는 테라스(일반 가격)인 경우가 많아 쓰지 않습니다. 거래표와 Excel에는 거래마다 같은 주택형 분양가와 프리미엄이 붙습니다. 단지 라벨은 분양권 거래 평균(평당가) 그대로입니다.

## 분석 보고서

상단 **분석 보고서** 버튼으로 사업지 인근 실거래를 객관적 수치로 정리한 보고서를 만듭니다. 판단 문구(적정·유사 등)는 넣지 않고, 판단은 보는 사람이 합니다.

보고서는 인구(수요) → 거래량 → 매매가 → 전월세 → 인근 단지 순으로 읽히게 짜여 있습니다. 지역 지표는 반경에 걸친 시군구와 **사업지 법정동**을 함께 보여 줍니다.

- **가. 인구·세대 — 수요 기반**: 주민등록 인구·인구 증감·세대수·세대 증감(연말 기준, 진행 중인 해는 최근 달 말), 순이동(전입−전출, 다른 시군구와의 이동 연간 합계). 사업지 법정동은 인구·세대만 (법정동 단위 순이동 자료 없음). 보고서를 먼저 띄우고 받는 대로 채운다
- **나. 주택 거래·가격 — 시장 흐름** (아파트, 기준연도 포함 최근 5개년)
  1. 매매 거래량 증감: 연도별 건수와 전년 대비 증감률. 기준연도가 아직 끝나지 않았으면 전년 같은 기간(예: 1~10월)과 비교하고 '동기'로 표시
  2. 매매 가격 추이: 평균 거래가, 전용 3.3㎡당 평균가 — 표와 꺾은선 그래프 (시군구·사업지 법정동 비교)
  3. 전월세 가격 추이: 전세 보증금, 월세 보증금·월세(괄호 안은 건수) — 표와 그래프
  - 사업지 법정동에 준공 아파트 거래가 없으면(분양권 단지만 있는 신도시 등) 줄은 남기고 빈칸 + 주석
- **다. 실거래 비교**: 준공 N년 이내(기본 15년), 기준 평형(기본 전용 84㎡) 매매의 단지별 연평균, 본건대비(= 최근 가격 ÷ 본건 세대당 분양가)
- **라. 법정동별 평균**: 평당가 = 평균 거래가 ÷ 환산 공급평(84타입 34평), 시군구 전체 평균과 순위
- **마. 분양권**: 공공데이터포털 「국토교통부_아파트 분양권전매 실거래가 자료」 활용신청이 필요합니다 (같은 인증키)
- **바. 요약 (수치)**: 인구 → 거래·가격 → 인근 단지 순으로 자동으로 쓰고 화면에서 고칠 수 있습니다 (인구 표가 늦게 채워지면, 요약을 고치지 않은 경우에만 인구 문장을 앞에 넣어 다시 씀)
- 필요한 기간(기준연도 4년 전 1월부터)의 실거래가 없으면 기간을 맞춰 자동으로 다시 분석합니다
- 내보내기: **PDF 받기**(화면 모양 그대로 A4), **Word 받기**(.docx, 표·그래프·문단), **Excel 받기**(지역 4개 시트 + 실거래 비교·동별 평균·분양권·요약, 천원), **인쇄**. 파일은 브라우저 기본 다운로드 폴더에 저장됩니다

### 인구·전입 지표 (행정안전부 주민등록 통계)

공공데이터포털에서 같은 인증키로 두 서비스 활용신청이 필요합니다.

| 서버 경로 | 서비스 | 비고 |
|---|---|---|
| `/api/pop-stat?sido=44&ym=202512` | 행정안전부_주민등록 인구 및 세대현황 (행정동) | 시도 하나의 시군구별 인구·세대수. 2022.09부터 |
| `/api/dong-pop?stdgCd=4413310800&ym=202512` | 행정안전부_법정동별(행정동 통반단위) 주민등록 인구 및 세대현황 | 사업지 법정동의 인구·세대수. **별도 활용신청 필요** (안 하면 표에 사유가 적힘) |
| `/api/pop-move?admmCd=4413300000&frYm=202510&toYm=202512` | 행정안전부_지역별 인구이동 현황 | 기간 3개월 이내, 2022.10부터. 전국 합계 코드가 없어 시도별로 나눠 부른 뒤 합친다 |

- 상류 응답이 느리다(호출당 4~7초). 처음 보는 지역은 1~3분 걸리고, 지난 달 자료는 브라우저(localStorage)와 Vercel CDN에 남아 다음부터 바로 나온다
- 일반구(천안시 서북구 등)의 전입·전출은 시 전체 값이다. 상류가 2024년 상반기까지는 구 단위로, 그 뒤로는 시 단위로만 주어 연도 기준을 시로 맞췄다
- 같은 시군구 안의 이동은 전입·전출에서 뺀다. 2022년은 10월부터라 전입·전출을 비운다

## 로컬 실행

지도·실거래·분석 보고서까지 PC에서 그대로 돌려 볼 수 있습니다 (Node.js 18 이상).

1. `.env.example`을 복사해 `.env.local`을 만들고 `DATA_SERVICE_KEY`, `KAKAO_JS_KEY`를 넣습니다. `.env.local`은 커밋되지 않습니다.
2. Kakao Developers의 JavaScript SDK 도메인에 `http://localhost:3000`을 등록합니다.
3. 처음 한 번 `npm install`, 그다음부터 `npm run local`을 실행하고 `http://localhost:3000`을 엽니다.

키를 바꾼 뒤에는 서버를 껐다 켜야 반영됩니다. 계산 테스트는 `npm test`로 돌립니다.
